## 直した点と原因(各1行)

1. PC幅のカードで題が語の途中で折れ、`(2/2枚目)` が語の途中に挟まる
   → 枚数バッジを題と同じ行の別カラムに置いていたため、題が2行になったとき2行目の語の途中に重なって見えていた。バッジを題の下の独立行へ移し、題は `joinTitleWords` で語中折り返しを禁止した。
2. 全画面表示の背景が透ける / 画像が上に寄る / 閉じるボタンに緑のフォーカス枠が残る / 見出しの `1 / 1` がカードの `(1/2枚目)` と別物
   → 背景色を指定していなかった(透明)。`#000` を敷いた。Web のクリック後に残る既定のフォーカス枠は `outlineWidth: 0` で消した。見出しはカードと同じ `(n/m枚目)` の書き方に揃えた。
3. iPhone幅で「154件」が二重に出る
   → 見出し(`headCountText`)と本文の「全154件中…」が同じ件数を別々に出していた。切っているとき(上限まで出しているとき)は見出しから件数を落とした。
4. 要対応の「28」がメニューアイコンに重なる / 一覧カードの完了・却下リンクが小さくて押しにくい
   → 札をアイコンの内側(右下)に絶対配置していたため三本線に重なっていた。アイコンの右上の外へ出した。完了・却下は `paddingVertical: 8` を取り、指で押せる高さにした。
5. 会話ペインに内部ID・開発者向けの文言が出る
   → カード本文の見出し(`【確認箱カード】…[ユーザーの発言]`)をそのまま表示していた。表示時だけ見出しを落とした。
